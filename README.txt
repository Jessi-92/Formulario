El formulario está dividido en varias partes:

1. Encabezado:
   Muestra el banner de HappyCel y el título principal del formulario.

2. Información general:
   Permite seleccionar la ciudad, la tienda y el número de auditores.
   Las tiendas cambian automáticamente según la ciudad seleccionada.

3. Información del vendedor:
   Registra el nombre, cédula y cargo del vendedor de la tienda auditada.

4. Validación de tienda:
   Sirve para revisar si el personal está uniformado y si el letrero se encuentra visible.
   Si el personal no está uniformado, se abre un campo para escribir el motivo.

5. Cuadre de caja:
   Permite validar si el formato del día anterior está cuadrado y firmado.
   También permite registrar si hubo faltante, sobrante o si la caja cuadró.
   Además, se debe cargar el archivo PDF correspondiente.

6. Cuadre de inventario:
   Permite revisar caja fuerte, transferencias pendientes y resultado del inventario.
   También permite cargar el inventario firmado en PDF y registrar comentarios.

7. Tabla de artículos faltantes:
   Si existen artículos faltantes, el formulario crea una tabla automática según la cantidad ingresada.
   Allí se coloca código, descripción, cantidad en kardex, cantidad física, diferencia y número GLP.

8. Archivos:
   Los archivos de cuadre de caja, inventario y faltantes no justificados se cargan en formato PDF.

9. Validaciones:
   Los campos marcados con * son obligatorios.
   El sistema no permite guardar si falta información requerida.

10. Mayúsculas:
   Todo texto que el usuario escriba se convierte automáticamente a mayúsculas.

11. Guardar:
   Por ahora el botón Guardar solo muestra un mensaje de confirmación.
   Todavía no guarda en base de datos ni en Google Sheets.
